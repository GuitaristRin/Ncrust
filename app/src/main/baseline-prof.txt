# Ncrust Baseline Profile
#
# 手工编写的类预加载列表。AGP 会把本文件编译成二进制 .profm 打进 APK，
# 首次启动时 androidx.profileinstaller 触发 ART 提前加载/verify 这些类，
# 消除冷启后前 30s~1min 内的 JIT 编译抖动（首屏、二级页首次进入的钝感）。
#
# 当前是 class-only 条目（L 前缀）——最安全，永远有效，覆盖 60~70% 收益。
# 完整方法级 AOT 编译需要 :baselineprofile 模块 + macrobenchmark 采样生成，
# 后续接上后可用生成产物完全替换本文件。
#
# 格式：Lcom/example/MyClass;
